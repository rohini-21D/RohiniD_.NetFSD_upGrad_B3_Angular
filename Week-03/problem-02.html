1. What is jQuery?
jQuery is a fast and lightweight JavaScript library used for DOM manipulation and event handling.
2. Why do we use jQuery?
It simplifies JavaScript coding and works across different browsers..
3. What is slideToggle() in jQuery?
slideToggle() shows or hides elements with a sliding animation.
4. What is a selector in jQuery?
Selectors are used to select HTML elements like class, id, or tag.
5. Can jQuery work with events?
Yes, jQuery handles events like click, hover, submit, and more.
