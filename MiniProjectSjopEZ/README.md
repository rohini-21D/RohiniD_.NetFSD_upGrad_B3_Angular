
ShopEZ – E-Commerce Application
================================


Overview
----------

ShopEZ is a front-end e-commerce web application that allows users to browse products, view details, add items to a cart, and proceed to checkout.
The project demonstrates core web development concepts using HTML, CSS, and JavaScript.


Features
----------
Product listing page

View detailed product information

Add items to cart

Update or remove items from cart

Checkout process

Dynamic data loading using JSON


Technologies Used
---------------------
HTML5 – Page structure

CSS3 – Styling and layout

JavaScript – Application logic

JSON – Product data storage


Product Listing
-----------------
Products are loaded dynamically from a JSON file

Displayed on the products page

Product Details
----------------

Clicking on a product shows detailed information

Cart Management
------------------
Users can add items to the cart

Supports updating quantity and removing items

Checkout
---------
Displays selected items

Final step for order placement


How to Run
-----------

Download or clone the project

Open the project folder

Open index.html in a web browser
